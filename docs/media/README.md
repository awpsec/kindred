# Showcase captures

These captures use the production UI and character renderer with synthetic API responses. The computer screen is a simulated demo document, not a recording of a live autonomous run. Names, conversations, resources and documents are fictional.

Run `KINDRED_PLAYWRIGHT_MODULE=/path/to/playwright node tools/frontend/capture-showcase.cjs` from the repository root to capture PNGs and animation frames. Convert the frames to GIF with an image tool before publishing. Inspect every image for personal data.
