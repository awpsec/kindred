# Mac voice input acceptance

`mac-voice-input.cjs` is an opt-in hardware fixture. It mounts the shipped dictation input selector and voice UI in an installed Kindred WKWebView, with the real microphone, AudioContext, AudioWorklet, PCM conversion, mute and playback. The call endpoint is a loopback fake provider. It never contacts a paid provider or saves microphone PCM. `capture-metadata.json` contains only device/engine metadata, frame/byte counts, aggregate RMS/peak, mute counters and playback counts. It does not prove provider speech recognition or a complete production call.

1. Start `node tools/frontend/fixtures/mac-voice-input.cjs /absolute/path/to/new-output`. Read the generated `fixture.json` for its loopback URL.
2. Launch the existing installed Mac executable against that URL, with `KINDRED_CLIENT_ONLY=1`, a test-only `KINDRED_ACCESS_TOKEN`, a fresh `KINDRED_PROFILE_ID`, and `KINDRED_PROFILE_SCOPE` equal to SHA-256 of `URL + "\n" + profile ID`. Keep the existing home and bundle/signature. Do not overwrite `profiles.json`, reset privacy permissions, or replace the app. Do not use the test window to manage production accounts.
3. In the local check window, use Refresh microphones and the real selector. If needed, choose “Choose a microphone…” to request capture permission and reveal device labels. Start a test, speak briefly, mute/unmute, play the synthetic tone, then end. Tests are capped at 45 seconds. Do a second call to check reacquisition. Match the track label, nonzero active frames and aggregate RMS, exact 1920-byte PCM frames, muted frames, playback events, and ended state to the user's observations. Capture no personal speech or screenshots of production content.
4. Stop only the owned fixture process, close its test window, reopen the normal app and verify saved-account metadata and the installed binary/signature are unchanged. Restore any system input/output selection changed during the check.

`KINDRED_TEST_VOICE_INPUT_BASELINE=1` serves the pinned pre-fix voice component from `d271cc42bbd7522407640a93687a689d52f9bede` with its matching hash. It should ignore an explicit input selection. `test-voice-input-selection.cjs` separately exercises the full app wiring, saved and changed inputs, missing/disconnected inputs, no silent fallback, System Default, and valid silent PCM in Chromium and WebKit. That automated check uses synthetic capture and is not hardware evidence.
